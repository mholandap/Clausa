# Clausa — site de apresentação

Página de apresentação do **Clausa**, uma plataforma em desenvolvimento para
**revisão contratual assistida e personalizável**, voltada a escritórios de
advocacia corporativa.

O Clausa aponta cláusulas de risco, organiza prazos e renovações e sugere
melhorias — sempre deixando a decisão final com o advogado.

## Sobre esta página

- Arquivo único: `index.html` (HTML, CSS e JavaScript, sem dependências externas além das fontes).
- Tema escuro por padrão, com alternância para o tema claro.
- Demonstração de análise de contrato por palavras-chave, executada no próprio
  navegador — nenhum texto é enviado a servidores.

> Protótipo de conceito. Nome, textos e números são ilustrativos e os contratos
> mostrados são fictícios.

## Como publicar (GitHub Pages)

1. Suba o `index.html` para a raiz deste repositório.
2. Em **Settings → Pages**, escolha a branch `main` e a pasta `/root`.
3. Em alguns minutos o site fica no ar em `https://<seu-usuario>.github.io/clausa-site`.
